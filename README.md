# OCULIDE Modern Academic UI/UX Skill Kit

Bộ skill thiết kế OCULIDE theo phong cách **Modern Academic SaaS**: tối giản, rõ nghiệp vụ, dễ dùng, nhất quán và có thể triển khai thật.

## Định hướng
- Deep Burgundy + Warm White + Charcoal.
- Bố cục đơn giản, ít card, ít trang trí.
- Ưu tiên bảng dữ liệu, bộ lọc và thao tác nghiệp vụ.
- Dashboard chỉ tóm tắt, không thay thế các module.
- Trải nghiệm riêng cho Admin, Giảng viên, Sinh viên.
